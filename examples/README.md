# Примеры

Исходные материалы, результат отбора и его изменение при смене интересов, выпуск для второй аудитории
и размеченные примеры датасета для сверки.
Выпуски получены 3 октября 2026 года командами ниже в чистой копии репозитория, модель `gpt-oss-120b`.

| Файл | Что это                                                                                                          |
|---|------------------------------------------------------------------------------------------------------------------|
| `articles.jsonl` | вход: 562 публикации из 28 источников за 4 сентября – 2 октября 2026 года, собраны `collect`, выгружены `export` |
| `soc.md` | ежедневный выпуск для SOC-аналитика: 264 публикации за 2 дня - 243 сюжета - 13 в выпуске                         |
| `soc_cloud.md` | тот же аналитик с интересами «облака и цепочка поставок»                                                         |
| `management.md` | ежемесячная сводка для руководства: 562 публикации за 30 дней - 507 сюжетов - 12 в выпуске                       |
| `dataset.jsonl` | 21 пример датасета организаторов с разметкой для `eval`; у 13 есть текст, загруженный `urls`, сайты 8 недоступны |

```bash
python cli.py import examples/articles.jsonl
python cli.py digest --profile soc --date 2026-10-02 --out examples/soc.md
python cli.py digest --profile soc_cloud --date 2026-10-02 --out examples/soc_cloud.md
python cli.py digest --profile management --date 2026-10-02 --out examples/management.md
python cli.py eval examples/dataset.jsonl
```

Модель отвечает не детерминированно: повторный прогон немного меняет подборку.
